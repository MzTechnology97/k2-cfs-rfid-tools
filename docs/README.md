## Historical research

The `history/` notes document older firmware and experiments; they are not current release instructions.
Old installable firmware and experimental tests are removed from the current branch and remain recoverable
from [the immutable pre-cleanup tree](https://github.com/MzTechnology97/k2-cfs-rfid-tools/tree/0ad22669248cc845a3c8d22dd613500c4b95feb3).
No Git history was rewritten. The base needed to rebuild RDG2 is recovered from that pinned commit into
an ignored cache; it is not an additional installable firmware in this tree.
